# AS3935 Lightning Detector

A project for detecting and monitoring lightning strikes using the AS3935 lightning sensor.

## Overview

This project interfaces with the AS3935 lightning detector IC to identify lightning activity and provide real-time storm detection capabilities.

## Features

- Real-time lightning detection
- Distance estimation to lightning strikes
- Storm activity monitoring
- Sensor configuration and calibration

## Hardware Requirements

- AS3935 Lightning Detector IC
- Microcontroller (Arduino, ESP32, STM32, etc.)
- I2C or SPI interface
- Supporting components (capacitors, resistors, antenna)

## Getting Started

1. Wire the AS3935 sensor to your microcontroller
2. Load the appropriate firmware
3. Configure the sensor parameters
4. Monitor lightning activity
